# 😀 Emoji Tasks

A modern Todo App with XP, Levels, Statistics and Emoji Tasks.

## ✨ Features

- Add tasks
- Complete tasks
- Delete tasks
- XP system
- Level system
- Progress bar
- Statistics dashboard
- LocalStorage saving
- Beautiful dark UI
- Emoji support
- Responsive design

## 🎮 XP System

- Complete task = +10 XP
- Every 100 XP = New Level

## 📊 Statistics

- Total tasks
- Completed tasks
- Active tasks
- Current XP
- Current Level

## 💾 Storage

All data is automatically saved using LocalStorage.

## 🚀 Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📱 Responsive

Works on:
- Desktop
- Tablet
- Mobile
